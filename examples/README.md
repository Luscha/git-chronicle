# Examples

- **`httpie.json`** (in `eval/`) — a question set for [httpie/cli](https://github.com/httpie/cli),
  with the facts taken from its CHANGELOG. Run it against a knowledge base built from that
  repository: `gitchronicle eval eval/httpie.json`.
- **`ledger.plan`** — what a curation ledger looks like once a real repository has been
  reviewed: standalone tools claimed, a blob split apart, folders that are shared on
  purpose marked as such.

Your own `gitchronicle.plan` and `gitchronicle.md` live at the root of the repository you
analyse, not here.
